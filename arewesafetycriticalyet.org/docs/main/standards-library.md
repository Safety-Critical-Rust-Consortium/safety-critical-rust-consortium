# Standards Library

The [Rust Foundation](https://rustfoundation.org/) has purchased the following safety standards for the Safety-Critical Rust Consortium. They are held in the consortium's shared drive so members can refer to the original text when working on coding guidelines, tooling, gap analyses and liaison activities.

## Access

- Access is available to **consortium members only**.
- Access is **read-only**: documents can be viewed online but **cannot be downloaded, printed, copied or redistributed**. This is required by the license terms of the standards publishers.
- To request access, [file a Standards Library access request](https://github.com/rustfoundation/safety-critical-rust-consortium/issues/new?template=standards_access.yml) on GitHub. You will be asked for the email address to share the drive with, the standards you need and what consortium work you need them for, and to agree to the terms of use above.

:::note

GitHub issues are public, so the name, email address and organization you enter in the request will be visible to everyone.

:::

Not a member yet? Membership is free. See [how to join](https://github.com/rustfoundation/safety-critical-rust-consortium#consortium-membership).
